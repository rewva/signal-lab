# signal-lab

A lab for building **faceless content channels + monetization tools** as a portfolio — spin up many cheap bets with an AI pipeline, find the one that gets *signal*, then concentrate effort and build the money behind it.

This is a **separate venture from WhichWise** (the finance comparison site). Different domain, different stack, different business model. It lives in its own repo on purpose.

**Status:** Planning / exploration. No code yet — see `docs/` for the strategy and plan we've locked so far.

## Start here

- `docs/strategy.md` — the core thesis: why most content/tool ideas fail, the moat filter that decides what survives, and the monetization truth.
- `docs/plan.md` — the operating playbook: the multi-channel test portfolio (spray to discover -> concentrate to monetize).
- `docs/idea-bank.md` — the running list of vetted, "chatbot-proof" ideas to draw test bets from.
- `CLAUDE.md` — focused context for AI sessions working in this repo.
